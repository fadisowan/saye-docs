في محرّر الثيم من لوحة سلة تبدأ الإعدادات العامة ببطاقة «تخصيص ساي»، ثم اثنتان وعشرون مجموعة مرتبة حسب الوظيفة: الهوية، ثم أعلى الصفحة، ثم المنتجات والصفحات، ثم السلة، ثم اللمسات والحركة، ثم الفوتر. كل مجموعة تنطبق على المتجر كله، وتُحفظ مرة واحدة.

| الترتيب | المجموعات |
|---|---|
| الهوية | الألوان والوضع الداكن، والخطوط والأحجام، واسم المتجر والشعار |
| أعلى الصفحة | شريط الإعلانات، والهيدر، والقائمة والشريط السفلي |
| المنتجات | بطاقة المنتج، والمنتجات في أقسام الرئيسية، وفتح المنتج والتصنيف |
| الصفحات | صفحة المنتج وأسفلها، وصفحة التصنيف والبحث، والماركات والحساب، وصفحة 404 |
| الشراء | السلة، وبعد الإضافة للسلة |
| اللمسات | شخصية المتجر، وواتساب، والترحيب وشاشة التحميل |
| الحركة | الحركة، والمؤشر والتأثيرات |
| أسفل الصفحة | الفوتر |
